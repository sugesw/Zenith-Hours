# 🎮 Zenith Hours · v3.2

**Multi-account Steam hour & trading card idler** with a live terminal panel.

Zenith Hours signs in to your Steam account(s) and reports a list of games as "playing", so Steam counts playtime and can drop trading cards. No game is downloaded or launched, so CPU, RAM and bandwidth usage stays minimal.

## ✨ Features

- Multiple accounts running at the same time
- Up to 32 games per account, with an independent list for each account
- Three login methods: QR code (recommended), username + password (Steam Guard supported), refresh token
- Live terminal panel showing status, idle time and earned hours
- Automatic reconnect and rate-limit handling
- Pauses automatically when you start a real game on the same account
- Ownership check (`--kontrol`) to find games that are missing from your library

## 🚀 Quick start

**Windows**
1. Install [Node.js](https://nodejs.org) 18 or newer.
2. Extract the ZIP and run `npm install` once in the folder.
3. Double-click `ZenithHours_Baslat.vbs` (or run `node index.js`).

**Android**
1. Install Termux and extract the ZIP.
2. Follow the step-by-step guide in `README.md`.

Full documentation (English & Turkish) is included in each package.

## 🔒 Privacy

Everything runs locally on your device. No data is collected, no telemetry, no external servers. Your password is never saved. See `PRIVACY.md` for details.

# 🇹🇷 Türkçe

**Çoklu hesap destekli Steam saat ve koleksiyon kartı kasma botu**, canlı terminal paneliyle birlikte.

Zenith Hours, Steam hesabına (hesaplarına) giriş yapar ve seçtiğin oyunları "oynuyormuş" gibi bildirir. Böylece Steam oynama süresini sayar ve kart düşebilir. Hiçbir oyun indirilmez veya açılmaz; işlemci, RAM ve internet kullanımı çok düşüktür.

## ✨ Özellikler

- Aynı anda birden fazla hesap
- Hesap başına en fazla 32 oyun, her hesabın kendi listesi var
- Üç giriş yöntemi: QR kod (önerilir), kullanıcı adı + şifre (Steam Guard destekli), refresh token
- Durum, kasma süresi ve kazanılan saati gösteren canlı terminal paneli
- Otomatik yeniden bağlanma ve hız sınırı yönetimi
- Aynı hesapla gerçek bir oyun açınca otomatik duraklatma
- Kütüphanende olmayan oyunları bulmak için sahiplik kontrolü (`--kontrol`)
